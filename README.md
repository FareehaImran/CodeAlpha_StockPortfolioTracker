# CodeAlpha Stock Portfolio Tracker

A simple Python program that calculates the total value of a stock portfolio. Made for the CodeAlpha internship (Task 2).

## How it works
- Stock prices are stored in a dictionary (hardcoded).
- The user enters a stock name and quantity, and types "done" to finish.
- The program shows each stock's value and the total investment.
- The result can be saved to portfolio.txt.

## How to run
python stock_tracker.py

## Concepts used
dictionary, input/output, loops, basic arithmetic, file handling, functions
